# Community guidelines

Be respectful, constructive, and considerate in issues, pull requests, reviews, and other project spaces. Discuss ideas and code without personal attacks. Welcome contributors with different backgrounds and experience levels.

Harassment, discrimination, threats, sexualized content, spam, and publishing another person's private information are not acceptable. This includes health records, account details, and credentials.

Maintainers may edit or remove inappropriate contributions, lock conversations, or restrict participation according to the circumstances. Use GitHub's reporting tools to report abusive content privately. Do not repeat private information in a public report. Security vulnerabilities belong in the private channel described in [SECURITY.md](SECURITY.md).
